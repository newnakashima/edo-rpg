# 曲の設計図（.song）の書式

`scripts/bgm/song.py` が読む、曲の設計図の書式です。コード進行と各パートの音を小節ごとに並べて書きます。
MIDI を直接書かず、この書式で書くのは、旋律とコードを同じ小節の中で見比べながら書けるようにし、検査でぶつかりを見つけるためです。
書いた例は [example.song](example.song) にあります。

## 全体の形

```
# 行頭の # はコメント。行の途中では「空白 + # + 空白」から後がコメント（音名の F# と区別するため）
title = 町（通常）       # 曲名
id    = bgm_town         # docs/audio.md の ID。出力のファイル名になる
tempo = 112              # 1 分間の四分音符の数
meter = 4/4              # 拍子（4/4, 3/4, 2/4, 6/8, 12/8 など）
key   = D major          # 調（主音 + 旋法。下の表）
intro = I                # 最初に 1 回だけ流す区間（省略可）
form  = A A2 B           # くり返す区間の順。最後まで行ったら form の頭（intro の後）へ戻る
loop  = yes              # ループしない曲（ファンファーレ・宿屋）は no
echo  = 112 0.35 0.22    # エコー: 遅延 ms（16 の倍数）、フィードバック、量。省略可

[parts]
# 名前   楽器       種類              オプション
melody   shinobue   notes             vol=100 pan=0
counter  koto       notes             vol=70  pan=-30 role=counter
harmony  koto       arp:up8           oct=4 vol=60 pan=25
bass     bass       bass:root-fifth   oct=2 vol=90
drums    drums      drums             vol=90

[section A]
chords  | D | G A | Bm | G A7 |
melody  | F#5:1 A5 B5:1/2 A5 F#5:1 | G5:1 B5 A5:2 | F#5:1 E5:1/2 D5 E5:1 F#5 | E5:3 r:1 |
drums   | O . t t O . t . | O . t t O . t . | O . t t O . t . | O . t t O t T T |
```

## 調（key）

`主音 旋法` で書きます。主音は `C`, `F#`, `Bb` など。

| 旋法 | 音（主音 C の場合） | 使いどころ |
| --- | --- | --- |
| major | C D E F G A B | 明るい曲 |
| minor | C D Eb F G Ab Bb（＋ A・B も調の音とみなす） | 暗い曲。V を長三和音（G・G7）にしてよい |
| dorian / phrygian / lydian / mixolydian | 教会旋法 | 色づけ |
| miyakobushi | C Db F G Ab（親: フリギア） | 都節。哀愁・不穏。和の定番 |
| minyo | C Eb F G Bb（親: 自然短音階） | 民謡。素朴・力強い |
| ritsu / yo | C D F G A（親: ミクソリディア） | 律・陽。明るい和風・雅楽風 |
| ryukyu | C E F G B（親: 長音階） | 琉球 |

五音音階の旋法でも、コードは親の七音音階の中から付けます（例: A minyo なら Am, Dm, Em, F, G, C、それに E・E7）。
検査は「旋律の音がそのときのコードに合っているか」を見るので、五音音階の外の音（例: A minyo の B や F）を使ってもエラーにはなりません。ただし和の雰囲気が薄れるので、五音音階の外の音の割合を情報として表示します。

## パート（[parts]）

`名前 楽器 種類 オプション…` を 1 行に 1 パート書きます。打楽器以外は 15 パートまで。同時に鳴る音の数の合計は 8 音までです（スーパーファミコンの音源の上限。検査で数える）。

楽器（`python3 scripts/bgm/song.py patterns` で音域も表示される）:

| 楽器 | 名前 | 音域 | 向き |
| --- | --- | --- | --- |
| shamisen | 三味線 | B2〜E6 | 旋律・刻み。すぐ減衰する |
| koto | 箏 | D3〜E6 | 分散和音・旋律。余韻が長い |
| biwa | 琵琶 | E2〜E5 | 重い場面の刻み |
| shakuhachi | 尺八 | C4〜E6 | ゆっくりした旋律。息の音 |
| shinobue | 篠笛 | G4〜C7 | 明るい旋律・祭り |
| hichiriki | 篳篥 | D4〜A5 | 雅楽風の旋律 |
| kokyu | 胡弓 | G3〜E6 | 泣きの旋律 |
| sho | 笙 | E4〜E6 | 和音の持続 |
| strings | 弦合奏 | E2〜C7 | 和音の下支え・対旋律 |
| brass | 金管 | Bb2〜C6 | ファンファーレ・重厚な場面 |
| bell | 鐘 | C4〜C7 | 飾りの音 |
| bass | ベース | E1〜G3 | 低音 |
| drums | 打楽器 | — | 種類も drums にする |

種類:

- `notes`: 音を 1 つずつ書くパート（旋律・対旋律・自分で書く低音）
- `drums`: 打楽器のパート
- 伴奏のパターン（コードから自動で音を作る。コードトーンだけを使うので、コードとぶつからない）:

| パターン | 内容 |
| --- | --- |
| `arp:up8` / `arp:up16` / `arp:up4` | 分散和音を下から上へ（8 分・16 分・4 分音符） |
| `arp:updown8` / `arp:updown16` | 上がって下がる分散和音 |
| `arp:alberti8` / `arp:alberti16` | 低・高・中・高 の分散和音 |
| `block:hold` | コードの間ずっと和音をのばす |
| `block:half` / `block:beat` | 2 拍ごと / 1 拍ごとに和音 |
| `block:off8` | 裏拍で和音を刻む |
| `bass:root` | 最低音をのばす |
| `bass:root4` / `bass:root8` | 最低音を 4 分 / 8 分音符で刻む |
| `bass:root-fifth` | 拍ごとに最低音と 5 度を交互に |
| `bass:octave8` | 8 分音符で最低音とその 1 オクターブ上を交互に |

オプション:

- `vol=0〜127`: 音量（初期値 100）
- `pan=-64〜63`: 左右（負が左）
- `oct=n`: パターンの音の高さの中心（和音は n オクターブ目の C 付近。初期値は和音 4、低音 2）
- `vel=1〜127`: 音の強さ（初期値 96）
- `gate=0.1〜1.0`: 音を鳴らす長さの割合（初期値は notes が 1.0、パターンが 0.9。スタッカートなら 0.5 など）
- `role=melody|counter|bass|harmony`: 検査での役割。省略すると、最初の notes パートが melody、楽器 bass と `bass:` のパターンが bass、ほかの notes が counter、パターンが harmony になる

## 区間（[section 名前]）

1 行目に `chords`、続けて各パートを `パート名 | 小節 | 小節 | … |` で書きます。

- 1 つのパートを複数の行に分けて書いてよい（続けて読む）。4 小節ごとに改行すると読みやすい
- どのパートも、小節の数を `chords` と同じにする
- 書かなかった notes / drums のパートは、その区間では休み。パターンのパートは、書かなければ [parts] のパターンで鳴る
- `パート名 off`: その区間だけ休ませる
- `パート名 @arp:updown8`: その区間だけパターンを変える
- `パート名 = A`: 区間 A の同じパートを写す（`chords = A` も使える）。写し元は写しでない区間にする
- パターンのパートに音を書くと、その区間だけ書いた音で鳴る

### コード

`| D | G A | Bm7 | Gmaj7:3 A7:1 |` のように書きます。

- 1 小節に複数のコードを書くと、長さを省いたものは残りを等分する。`G:3 A:1` のように長さ（四分音符 = 1）も書ける
- 書ける種類: `C`, `Cm`, `C7`, `Cmaj7`（`CM7`）, `Cm7`, `CmM7`, `Cm7b5`, `Cdim`, `Cdim7`, `Caug`, `Csus4`, `Csus2`, `C7sus4`, `C6`, `Cm6`, `Cadd9`, `Cmadd9`, `C9`, `Cmaj9`, `Cm9`, `C7b9`, `C7#9`, `C7b13`, `C11`, `Cm11`, `C13`, `C5` など
- 分数コード（転回形）: `C/E`, `D/F#`。低音のパートは / の後の音になる
- 無音・コードなし: `N.C.`

### 音（notes のパート）

`音名:長さ` を空白で区切って並べます。1 つのパートで同時に鳴らせるのは 1 音だけです（和音を自分で書くときは、パートを分けるか、伴奏のパターンを使う）。

- 音名: `C4`（中央のド = MIDI 60）, `F#5`, `Bb3`。音名は大文字、オクターブの数字は必須
- 休符: `r`
- 長さ: 四分音符 = 1。`2`（2 分）, `1/2`（8 分）, `1/4`（16 分）, `3/2`（付点 4 分）, `1/3`（3 連符の 8 分）。小数 `0.5` も書ける。拍子が 6/8 でも四分音符 = 1 で数える（付点 4 分 = `3/2` が 1 拍）
- 長さを省くと、同じパートの直前の音と同じ長さになる（区間の頭では 1）
- 小節の長さの合計がぴったり合わないとエラーになる
- 印（音の後ろに付ける）:
  - `~`: 次の音とつなぐ（タイ）。次の音は同じ高さにする。小節線・区間をまたいでよい
  - `>`: アクセント（強く）
  - `!`: 意図した不協和音。検査でエラーにしない。使うときは、その行の前のコメントに意図を書く

### 打楽器（drums のパート）

1 小節を同じ長さのマスに分けて、記号を並べます。マスの数は小節ごとに自由です（8 個なら 8 分音符、16 個なら 16 分音符、6/8 拍子で 6 個なら 8 分音符）。

| 記号 | 音 |
| --- | --- |
| `O` | 大太鼓（低くて重い） |
| `M` | 桶胴太鼓（中くらい） |
| `T` | 締太鼓（高くて硬い） |
| `K` | 鉦（チャンチキ） |
| `H` | 拍子木 |
| `W` | 木魚・ウッドブロック |
| `B` / `S` / `R` | バスドラム / スネア / リムショット |
| `X` / `Y` / `C` | ハイハット（閉）/（開）/ シンバル |
| `.` | 休み |

大文字は強く、小文字は弱く叩きます（`T` と `t`）。同時に叩くときは `O+K` のように + でつなぎます。

## 検査と書き出し

```bash
python3 scripts/bgm/song.py check audio-src/bgm/bgm_town.song      # 検査（-v で情報もすべて表示）
python3 scripts/bgm/song.py roll  audio-src/bgm/bgm_town.song -o /tmp/roll.png   # ピアノロール
python3 scripts/bgm/song.py midi  audio-src/bgm/bgm_town.song      # エラーがなければ .mid を書く
```

MIDI には、ループの位置のマーカー（`loopStart` / `loopEnd`）とエコーの設定が書かれ、[bgm-render スキル](../bgm-render/SKILL.md) の書き出しで使われます。
