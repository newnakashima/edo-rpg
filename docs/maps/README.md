## 通しの確認（全 40 マップ）

すべてのタイルセットを部品で描き直した後（castle まで）、全 40 マップを `scripts/mapkit/map_shot.mjs` で撮り直し、`map-composition` スキルの手順 7 のチェック項目を通しで確かめた。撮った画像は上の「後」と同じなので、ここには新しく置いていない（撮り直すときは `npm run dev` のあと、マップ ID ごとに `node scripts/mapkit/map_shot.mjs <マップID> <出力.png>`）。

| チェック項目 | 結果 |
| --- | --- |
| 2 × 2 マスより大きな物が 1 枚の柄の繰り返しになっていない | ○（森・岩・水・屋根・壁は、すべてのマップで境目・端の部品で描かれている） |
| 地形が接する所に縁がある | ○ |
| 家の屋根に棟・軒先・左右の端、壁の両端に柱がある | ○（建物のあるマップすべて） |
| 部品の透明な所から黒い背景が見えない | ○ |
| 同じタイルセットのほかのマップも崩れていない | ○（各タイルセットの PR のあとに入った変更で崩れたマップはない） |

残っている点（仕組みを足すまで直せないもの。State のタスクの「必要になったら」に対応する）:

- 広い地面・床・屋根の面が同じ柄の繰り返しに見える（江戸の地面、屋内・蔵・からくり・船・城の板の床、大火の屋根と焼け跡、ワールドマップの山と海の波）。柄違いの仕組みがまだない。
- L 字・コの字の物（からくり蔵の機械、清正の古井戸の底の橋）は入り隅の部品がなく、rows の形どおりの段になる。
- 道場の床（伊賀者の里）や大手門（江戸）など、専用の部品を作っていない所は共通の画像・ほかの建物と同じ部品を使っている。
