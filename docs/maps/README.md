# マップの描き直しの記録

描き直したマップの、変える前（左）と後（右）の全体の画像（`scripts/mapkit/map_shot.mjs` で撮った地形だけのもの）。

- `shimizu.png`・`hiroshima.png`: 港町（minato）
- `urayama.png`・`harajo.png`: 野山（yama）
- `kitsunebiCave.png`・`kiyomasaIdo.png`: 洞窟（cave）
- `sunpu.png`・`yoriki.png`・`sendai.png`・`hikone.png`・`kumamoto.png`: 武家の城下（bushi）
- `nagoya.png`・`hamamatsu.png`・`osaka.png`: 商人の町（shoka）。部品は前から使っていて、通れるマスの地面・草・道の配置だけを整えた
- `kyo.png`: 京の町家（miyako）
- `iga.png`・`igaSato.png`・`kagiya.png`: 山里（sato）
- `nagasaki.png`・`dejima.png`: 南蛮の町（nanban）
- `kanazawa.png`・`kenrokuen.png`・`aizu.png`: 雪の町（snow）。会津若松は家の前と間の草を雪の地面にした
- `edo.png`: 江戸の長屋（nagaya）。地面ばかりだった裏庭と空き地に草のかたまりを作った
- `kobo.png`・`takoya.png`: 屋内（interior）。入口のまわりを土間、座元の間・凧屋の居間と奥の作業場を畳にした
- `world.png`: ワールドマップ（field）。大きいので、変える前（上）と後（下）に並べた
