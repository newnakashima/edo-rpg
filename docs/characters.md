# 登場人物と職業

## パーティー

パーティーは主人公と仲間 3 人の最大 4 人です。職業は人物ごとに固定し、技の系統が異なります。

| 人物 | 職業 | 加入 | 役割 |
| --- | --- | --- | --- |
| 主人公（弥太郎 / お志乃） | 渡世人 | 最初から | 攻守のバランス型。仲間をかばう |
| 霞（かすみ） | 忍者 | 第 1 章 | 素早さが高い。連続攻撃、状態異常 |
| 玄道（げんどう） | 破戒僧 | 第 3 章 | 回復とお祓い。力も強い |
| お凛（おりん） | 鉄砲打ち | 第 4 章 | 遠距離の高威力。からくり鉄砲で属性弾を撃つ |
| 榊兵庫（さかき ひょうご） | 侍 | 第 5 章のみ（一時加入） | 単体への強力な剣技 |

### 主人公（渡世人）

- 男: 弥太郎。三度笠に縞の合羽、長脇差。口数は少ないが義理堅い。
- 女: お志乃。同じ装い。女だてらに渡世の世界を生きてきた。
- 技（仁義・博打）: 「仁義を切る」（敵 1 体の攻撃を自分に引きつける）、「かばう」、「居合」（単体の強攻撃）、「丁半博打」（ランダムで大ダメージか空振り）、「一宿一飯の恩」（味方全体の小回復）

### 霞（忍者）

- 公儀隠密のくノ一。冷静で口が悪い。伊賀の出だが、里を抜けている。
- 技（忍術）: 「手裏剣」（2〜3 回攻撃）、「煙玉」（敵全体の命中を下げる）、「痺れ薬」（麻痺）、「影縫い」（敵 1 体の行動を 1 回止める）、「分身の術」（回避を上げる）

### 玄道（破戒僧）

- 大酒飲みで寺を追われた僧。金剛杖を振るう怪力。人を斬ることを嫌い、「祓う」ことにこだわる。
- 技（法力）: 「薬師の真言」（単体回復）、「般若心経」（全体回復）、「お祓い」（状態異常の回復）、「喝」（妖怪・からくりに大ダメージ）、「金剛力」（攻撃力を上げる）

### お凛（鉄砲打ち）

- 辰五郎の一人娘。気が強く、町の男衆より腕っぷしが強い。父の形見のからくり鉄砲を使う。
- 技（からくり鉄砲）: 「狙い撃ち」（単体の強攻撃、必中）、「散弾」（敵全体）、「火薬弾」（火属性）、「雷管弾」（からくりに大ダメージ）、「早合」（2 回撃つ）

### 榊兵庫（侍）

- 大坂の元与力。民を思う清廉な侍。一時加入のゲストで、プレイヤーは操作できるが装備は変えられない。
- 技（剣術）: 「袈裟斬り」、「燕返し」（2 回攻撃）、「無念無想」（会心率を上げる）

## 職業

プレイヤーキャラクターの職業のほか、敵として登場する職業もあります。

| 職業 | 主に使う人物 | 系統 |
| --- | --- | --- |
| 渡世人 | 主人公 | 仁義・博打 |
| 忍者 | 霞、敵の伊賀者 | 忍術 |
| 破戒僧 | 玄道、敵の生臭坊主 | 法力 |
| 鉄砲打ち | お凛、敵の鉄砲足軽 | からくり鉄砲 |
| 侍 | 榊兵庫、敵の浪人・旗本 | 剣術 |
| 妖術師 | 夜叉丸、敵の外法使い | 妖術（敵専用） |
| からくり師 | 敵の工房の職人 | からくり（敵専用） |

## 能力値

| 能力値 | 意味 |
| --- | --- |
| HP（体力） | 0 になると戦闘不能 |
| MP（気力） | 技・術を使うと減る |
| 攻撃 | 物理攻撃のダメージ |
| 防御 | 物理攻撃のダメージを減らす |
| 術力 | 術のダメージと回復量 |
| 素早さ | 行動順、逃走の成功率 |
| 運 | 会心、状態異常のかかりやすさ |

成長率と各レベルの値は [balance.md](balance.md) で定義します。
