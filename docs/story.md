# ストーリー

架空の江戸時代を舞台にした和風 RPG のストーリーです。章立て、各章の事件、下敷きにする江戸時代の実在エピソードをまとめます。
地名・城下町は実在のものを使い、登場人物と事件は架空とします（実在の人物名は使わない）。

## あらすじ

流れ者の渡世人（主人公）は、用心棒の仕事で食いつなぎながら街道を渡り歩いている。廻船問屋の荷の護衛を終えた主人公は、駿河の清水湊で一家を構える親分・**鬼瓦の辰五郎**のもとで一宿一飯の世話になる。
辰五郎は「町から人が消える。神隠しだと皆は言うが、どうも臭う」と主人公に相談を持ちかける。

調べを進めると、消えた人々は**からくり兵**の動力（「魂のゼンマイ」）にするためにさらわれていたことが分かる。
からくり兵を量産しているのは、将軍の影武者を操り幕府を牛耳ろうとする老中・**鷲尾但馬守宗衡（わしお たじまのかみ むねひら）**の一派だった。
鷲尾は長崎の出島から流れてきた南蛮の機械学と、妖術師の外法を組み合わせ、からくりの軍勢で天下を握ろうとしている。

主人公は公儀隠密の忍者・霞、京で出会う破戒僧・玄道とともに、鷲尾の陰謀を追って日本各地を旅する。
旅の途中で辰五郎が鷲尾配下の刺客に殺され、その娘・お凛が仇討ちを誓って一行に加わる。
一行は伊賀上野で仇を討ち、大坂、長崎、金沢を経て、ついに江戸へ。江戸城の奥、将軍の間で鷲尾と対峙する。

鷲尾は敗れ、幽閉されていた本物の将軍が戻る。仲間たちはそれぞれの道へ帰り、主人公は再び気の向くままの流れ者に戻る。
ただ一人、お凛だけがその旅についていく。

### 序章「一宿一飯」（駿河・清水湊）

- 廻船問屋の荷を清水湊まで護衛する用心棒の仕事を終えた主人公が、雨の夜に辰五郎一家の門をくぐり、仁義を切る（チュートリアルの会話）。
- 辰五郎から「町の者が月に一人、二人と消える」と相談を受ける。娘のお凛は「よそ者に頼るなんて」と反発する。
- 茶屋・長屋で聞き込み。消えた者は皆「夜に狐火を見た」と言い残していた。寺の和尚は、江戸で評判になった「天狗にさらわれて帰ってきた少年」の聞き書きを引き合いに出し、さらわれた者は生きているかもしれないと言う。
- 裏山の「狐火の洞」へ。妖狐を倒すと、奥に木箱と、ゼンマイの仕掛けが埋め込まれた人形の残骸が見つかる。箱には駿府の工房の焼き印。
- ボス: **野狐（やこ）**（妖狐。実はからくりで操られていた）
- 町の施設: 茶屋、旅籠、よろず屋、辰五郎一家の屋敷、長屋、寺（清見寺がモデル）

### 第 1 章「からくり屋敷」（駿府城下）

- 駿府の城下では、大坂・道頓堀から巡業に来たからくり一座の興行が評判になっている。興行主の工房に忍び込もうとして、同じく工房を探っていた忍者・霞と鉢合わせる。
- 霞は公儀隠密で、「江戸の上の方」の指図でからくりの出どころを追っていた。利害が一致して手を組む（霞 加入）。
- 武家屋敷に住む町奉行所の与力が工房をかばっていることが分かる。与力の屋敷の蔵から、さらわれた人の名簿が見つかる。
- からくり屋敷（ダンジョン）の最深部で、人をゼンマイに封じる装置と、妖術師・夜叉丸に出会う。夜叉丸は装置を壊して逃げる。
- 封じられていた人々を助け出すが、何人かは手遅れだった（切ない別れ：ゼンマイに封じられた母が、最後に子守唄のからくり音を鳴らす）。
- ボス: **からくり大将 鉄瓶（てつびん）**（からくり兵の指揮機）

### 第 2 章「金鯱の夜」（東海道 → 尾張名古屋）

- 東海道を西へ。宿場町（府中、掛川、浜松）を抜ける街道でランダムエンカウント。大井川の川越し人足のイベント。
  - 実装（PR #18）: 宿場町はワールドマップの東海道の出現範囲（tokaido）として抜けるだけにし、町のマップは作っていない。浜松は寄り道の城下町（下の表）として、寄り道をまとめて作るときに足す。
- 名古屋城の金の鯱の鱗が盗まれる事件が起き、町は大騒ぎ。疑いをかけられたのは、凧に乗る芸で評判の軽業師・金太。
- 金太は無実で、鱗を盗んだのは鷲尾の配下。金はからくり兵の「心臓」の材料になっていた。
- 金太の大凧で城の天守へ。鱗を取り返し、金太の無実を晴らす。金太は罪をかぶっていた兄を救えず、兄はからくり兵として倒れる（悲しい別れ）。
- ボス: **金鯱からくり**（金の鱗で動く巨大な鯱）

### 第 3 章「鬼の都」（京）

- 京では夜な夜な鬼が出ると噂。羅生門跡に鬼が出るという。
- 鴨川の河原で、酒に酔って寝ている破戒僧・玄道と出会う。玄道は寺を追われた身だが、鬼退治を請け負っている。
- 鬼の正体は、妖術で鬼の姿に変えられた河原者たち。玄道は彼らを「斬らずに祓う」ことにこだわる。一行も手伝い、玄道が加入する。
- 鬼の巣（大江山を思わせる山寺の廃墟）で夜叉丸と再戦。夜叉丸の口から、黒幕が「江戸の老中」であることがほのめかされる。
- 同じころ、清水湊で辰五郎が鷲尾配下の刺客に殺される。飛脚が急報を届ける：「辰五郎親分、殺される」。
- ボス: **酒呑の大鬼**（夜叉丸が呼び出した鬼）
- 実装（第 3 章の PR）: 京 → 鴨川の河原で玄道が加入 → 羅生門跡で鬼（河原者）を祓う → 北の山の鬼の巣で夜叉丸と大鬼 → 京に戻ると飛脚の急報（`chapter3Cleared`）。辰五郎は `chapter3Cleared` で清水湊から姿を消す（弔いの場面は第 4 章で足す）。夜叉丸との「再戦」は、夜叉丸が大鬼を呼んで逃げる形にした（夜叉丸と戦うのは第 7 章）。

### 第 4 章「鍵屋の辻」（清水湊 → 伊賀上野）

- 清水湊へ戻ると、一家は辰五郎の弔いの最中。お凛は父の形見のからくり鉄砲を手に、仇討ちを誓う。
- 下手人は鷲尾配下の刺客・蛇骨の権六。権六は伊賀上野へ逃げたという。お凛が一行に加わる（ヒロイン加入）。
- 仇討ちには公儀の許し（仇討免状）が要る。霞のつてで、江戸の町奉行所に届け出る手続きを飛脚で行うイベント。
- 伊賀の山中で、伊賀者の里（忍者屋敷のダンジョン）を抜ける。霞のかつての師との対決。
- 伊賀上野・鍵屋の辻で権六を討つ。権六は死の間際に「親分はおれたちの仲間になるのを断った」と言い残す。
- ボス: **蛇骨の権六**（刺客。からくりの義手を持つ）
- 実装（第 4 章の PR）: 第 3 章を終えて清水湊に入ると辰五郎の弔い（`shimizuEnter`）。お凛が加入し（`orinJoined`、初期装備は形見のからくり銃）、霞が仇討免状の願いを飛脚に託す → ワールドマップの伊賀を `orinJoined` で開く → 伊賀上野に着くと江戸から免状が届く → 北の山の伊賀者の里（忍者屋敷）の奥で霞の師・朧（中ボス）と戦う（`oboroDefeated`）。朧から権六が夜明けに鍵屋の辻を通ると聞く → 城下の西の鍵屋の辻で権六を討つ（`gonrokuDefeated`、`chapter4Cleared`）。権六は「親分は仲間になるのを断った」と言い残し、大坂へ向かう手はずだったと分かる（第 5 章への導線）。

### 第 5 章「天下の台所」（大坂）

- 大坂では米の値が吊り上がり、町人が飢えている。米問屋が鷲尾の手先となり、米を買い占めている。
- 霞は鷲尾の動きを江戸の上役に報告するため、一時パーティーを離れる。
- 元与力の侍・榊兵庫が、民を救うため蜂起を企てている。一行は一時的に兵庫と行動をともにする（兵庫 一時加入）。
- 一行は蜂起による大火を避けるため、米蔵の地下にあるからくり工場をつぶす作戦を立てる。
- 蜂起は止められず、兵庫は町を焼かないよう自ら奉行所に名乗り出る（切ない別れ）。
- ボス: **米蔵の守り神 百俵からくり**
- 実装（第 5 章の PR）: 大坂を `chapter4Cleared` で開く → 着くと米の買い占めの話と、霞の一時離脱（`leave`、`kasumiAway`。経験値と装備は `away` に預ける。広島で落ち合う約束）→ 長屋の私塾で榊兵庫に会い、兵庫が一時加入（ゲスト Lv18、`hyogoJoined`）、米蔵の用心棒がどく → 米蔵の地下のからくり工場で百俵からくり（`hyakuhyoDefeated`）→ 大坂に戻ると門弟たちの蜂起、兵庫は火を放たせず自ら奉行所へ（`leave`、`chapter5Cleared`）。霞からの文で広島へ（第 6 章で霞が復帰）。

### 第 6 章「南蛮からくり」（長崎・出島 → 島原）

- 西国街道を西へ。途中の城下町・広島で霞が戻ってくる（霞 復帰）。
- からくりの源流を探り、長崎（幕府の直轄地）へ。出島のオランダ商館の通詞から、南蛮の機械学の書物が密かに持ち出されたと聞く。
- 南蛮寺の跡、島原の古城の跡（ダンジョン）で、からくりと外法を融合させた研究所を見つける。
- 研究所の主は、異国の機械学に魅せられた蘭学者。鷲尾に利用されていたことを悟り、からくりの弱点（魂のゼンマイを解き放つ祝詞）を一行に託して倒れる。
- ボス: **南蛮大筒からくり**

### 第 7 章「百万石の影」（北前船 → 加賀金沢）

- 長崎から北前船に乗って日本海を北上し、金沢へ。船上でのイベント戦闘（海の妖怪）。
- 加賀ではお家騒動の最中。家老が藩主を「病」と称して閉じ込め、影武者を立てている。影武者の正体はからくり人形。
- これは江戸で鷲尾が将軍にしていることの試しだったと分かる。
- 兼六園を思わせる庭園と、城の地下のからくり蔵を攻略し、藩主を救い出す。藩主から、江戸城に入るための手形を授かる。
- 夜叉丸との決着。夜叉丸は鷲尾に家族を人質に取られていたことを明かす。
- ボス: **夜叉丸**（最終形態）

### 第 8 章「火事と喧嘩は江戸の華」（江戸の町）

- 金沢から北国街道を経て、奥州の仙台へ。仙台藩の重臣から、鷲尾が東北の諸藩にもからくりの影武者を送り込もうとしていると聞き、奥州街道を南下して江戸に入る。
- 江戸に入ると、鷲尾は一行を謀反人として手配しており、表立って動けない。
- 長屋に身を潜め、町火消しの組（め組がモデル）、義賊の鼠小僧（ここでは「鼠の小吉」）の協力を得る。
- 町の噂で、将軍が人前に出なくなり、まれに出ても能面のように表情がないことを知る。小吉が江戸城に忍び込み、将軍の影武者がからくりであることを確かめてくる。
- 鷲尾は江戸の町に火を放ち、混乱に乗じてからくり兵で城を固めようとする。八百屋お七の伝承を下敷きにした、恋のために火付けをそそのかされた娘のイベント。
- 火消しとともに大火を止め、混乱の中で江戸城へ潜り込む。
- ボス: **火車からくり**

### 終章「将軍の間」（江戸城）

- 江戸城の大奥、松の廊下、御金蔵を抜けるダンジョン。各フロアで、これまでの章の人物が助けに来るイベント。
- 松の廊下で、鷲尾の腹心の旗本・鬼塚典膳との決闘（刃傷事件の伝承を下敷きにする。中ボス戦）。
- 将軍の間で、からくりの影武者を操る鷲尾と対峙する。
- ボス: **鷲尾但馬守宗衡** → 最終形態 **からくり大権現**（鷲尾が自らをからくりと融合させた姿）
- エンディング: 本物の将軍が戻る。霞は隠密の務めへ、玄道は新しい寺へ。主人公は名乗らずに江戸を去り、再び流れ者に。街道の茶屋で、旅支度のお凛が待っている。

## 主人公の男女差

- 性能は同じ。見た目（歩行グラフィック・顔グラフィック）と、一部の台詞（一人称、お凛との掛け合い）が変わる。
- 男: 弥太郎（やたろう）。一人称「あっし」。
- 女: お志乃（おしの）。一人称「あたし」。女渡世人。
- エンディングでお凛がついていく場面は、男女どちらでも同じ流れとし、台詞だけを変える。
