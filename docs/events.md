# イベントスクリプト

シナリオの会話・分岐・戦闘などは、コードを書かずにデータ（`src/data/events.ts`）として足します。
形は `src/data/eventTypes.ts`、実行は `src/systems/eventScript.ts`（画面に依存しない）、画面への組み込みは `src/scenes/FieldScene.ts` です。

## イベントを始めるきっかけ

| きっかけ | 書く場所 |
| --- | --- |
| 人や物に話しかける | `maps.ts` の NPC に `event: 'イベントの ID'` |
| マップに入る | マップに `onEnter: { event, unless }` |
| 決まった場所に乗る | マップに `triggers: [{ x, y, event, unless }]` |

`unless` に書いたフラグが立っていれば、そのイベントは始めません（一度きりのイベントに使う）。
`unless` のフラグはイベントの中で `setFlag` で立てます。踏むトリガーで立て忘れると、そのマスを踏むたびに始まるので、`unless` と `setFlag` は組で書きます。
`warp` や全滅で別のマップに移ったときは、途中のイベントが終わってから、移った先のマップの `onEnter` を行います（同じマップで戦闘から戻っただけなら行いません）。

## 姿を消す NPC・入れる町・出現範囲のフラグ

- NPC に `hideFlag` を書くと、そのフラグが立ったら姿を消します（仲間になった人、どいた見張りなど）。イベントの途中で立てた場合は、イベントが終わったとき、または戦闘や移動でフィールドに戻ったときに消えます。消すのを台詞に合わせたいときは、立てる位置を台詞のすぐあとにします。
- 出口のマスに見張りの NPC を立たせておけば、フラグが立つまでその先へ進めないようにできます。
- ワールドマップの町の印に `openFlag` を書くと、そのフラグが立つまでは入れず、`lines` を出します。
- ワールドマップの関所（`gates`）は `flag` が立つまで通れません。`event` を書くと、通れないときに `lines` の代わりにそのイベントを行います（大井川の川越しのように、関所を開けるイベントに使う。イベントの中で `flag` を立てる）。
- `encounterZones` の範囲に `flag` を書くと、そのフラグが立っているときだけその範囲の出現表を使います（立つまでは、あとに書いた範囲かマップ全体の出現表）。
- 町でないマップ（ダンジョンなど）に `respawnMap` を書くと、そこで全滅したときにその町の旅籠の前へ戻ります。
- ワールドマップのように地域がまたがるマップには `respawnZones`（範囲と町）を書くと、その範囲で全滅したときにその町へ戻ります（`respawnMap` より優先）。範囲に `flag` を書くと、そのフラグが立っているときだけその範囲を使います（伊賀のまわりは、お凛が加わるまでは名古屋へ戻る）。

イベントが参照する道具・敵・仲間・移動先は、`src/data/events.test.ts` が確かめます。

## 手順

| type | 内容 |
| --- | --- |
| `say` | 台詞（1 要素が 1 ページ）。`{hero}` は主人公の名前。`linesF` があれば女主人公のときはそちら。名前の後ろに〈怒〉〈悲〉を書くと、その表情の顔を出す（例: `霞〈怒〉「……」`。印は画面に出ない。表情差分は主人公と仲間だけ。`src/data/faces.ts`） |
| `setFlag` | フラグを立てる（`value: false` で下ろす） |
| `if` | フラグが立っていれば `then`、なければ `else` |
| `choice` | 選択肢。選んだ `steps` を行い、そのあと続きに戻る |
| `giveItem` / `giveMoney` | 道具・装備品、お金を渡す。持ちきれない（99 個を超える）道具は渡さず、`ifFull` があればそれを行う |
| `join` | 新しい仲間を加える（パーティーの平均レベル〈切り捨て、最低 1〉、加入時の装備）。ゲスト（`guestLevel` のある人物。第 5 章の榊兵庫）はそのレベルで加わる。加入済み・一時離脱中（`away` にいる）・満員なら何もしない。一時離脱からの復帰は `rejoin` を使う |
| `leave` | 仲間を一時的に抜く。経験値と装備は `away` に預ける（第 5 章の霞）。ゲストは預けずに抜ける。主人公と、いない仲間には何もしない |
| `rejoin` | 一時離脱中（`away` にいる）の仲間を戻す（第 6 章の霞）。装備はそのまま、経験値はその時点のパーティーの平均レベル（切り捨て）まで引き上げ（下げない）、HP・MP は満タン。`away` にいない・満員なら何もしない |
| `heal` | 全員を全回復する |
| `battle` | 戦闘。勝つか逃げれば続きへ。`canEscape` を省くと逃げられない。`ifLose` があれば負けても全滅にせず（倒れた仲間は HP 1 で起き上がる）、`ifLose` を行う。なければ通常の全滅でイベントは終わる |
| `warp` | 場所を移す（移った先で続きを行う） |
| `end` | ここで終える |
| `ending` | イベントを終え、エンディング（仲間たちの行く末を流して「完」を出し、タイトルへ戻る。`src/scenes/EndingScene.ts`）を出す。終章のからくり大権現を倒したあとに使う |

## 例

```ts
myEvent: {
  id: 'myEvent',
  steps: [
    { type: 'if', flag: 'done', then: [{ type: 'say', lines: ['もう用はない'] }], else: [
      { type: 'say', lines: ['{hero}、頼みがある'] },
      { type: 'choice', prompt: '引き受けるか？', options: [
        { label: 'はい', steps: [{ type: 'battle', enemies: ['yamainu'], level: 2 }, { type: 'setFlag', flag: 'done' }] },
        { label: 'いいえ', steps: [{ type: 'end' }] },
      ] },
    ] },
  ],
},
```

戦闘や `warp` でフィールドを離れる間、途中のイベントは `state.ts` が預かり、戻ってきたフィールドが続きを行います。途中のイベントはセーブしません（記録は旅籠・飛脚でだけ行うため、イベントの途中で記録されることはない）。
