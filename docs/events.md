# イベントスクリプト

シナリオの会話・分岐・戦闘などは、コードを書かずにデータ（`src/data/events.ts`）として足します。
形は `src/data/eventTypes.ts`、実行は `src/systems/eventScript.ts`（画面に依存しない）、画面への組み込みは `src/scenes/FieldScene.ts` です。

## イベントを始めるきっかけ

| きっかけ | 書く場所 |
| --- | --- |
| 人や物に話しかける | `maps.ts` の NPC に `event: 'イベントの ID'` |
| マップに入る | マップに `onEnter: { event, unless }` |
| 決まった場所に乗る | マップに `triggers: [{ x, y, event, unless }]` |

`unless` に書いたフラグが立っていれば、そのイベントは始めません（一度きりのイベントに使う）。
`unless` のフラグはイベントの中で `setFlag` で立てます。踏むトリガーで立て忘れると、そのマスを踏むたびに始まるので、`unless` と `setFlag` は組で書きます。
`warp` や全滅で別のマップに移ったときは、途中のイベントが終わってから、移った先のマップの `onEnter` を行います（同じマップで戦闘から戻っただけなら行いません）。

## 姿を消す NPC・入れる町・出現範囲のフラグ

- NPC に `hideFlag` を書くと、そのフラグが立ったら姿を消します（仲間になった人、どいた見張りなど）。イベントの途中で立てた場合は、イベントが終わったとき、または戦闘や移動でフィールドに戻ったときに消えます。消すのを台詞に合わせたいときは、立てる位置を台詞のすぐあとにします。
- 出口のマスに見張りの NPC を立たせておけば、フラグが立つまでその先へ進めないようにできます。
- ワールドマップの町の印に `openFlag` を書くと、そのフラグが立つまでは入れず、`lines` を出します。
- ワールドマップの関所（`gates`）は `flag` が立つまで通れません。`event` を書くと、通れないときに `lines` の代わりにそのイベントを行います（大井川の川越しのように、関所を開けるイベントに使う。イベントの中で `flag` を立てる）。
- `encounterZones` の範囲に `flag` を書くと、そのフラグが立っているときだけその範囲の出現表を使います（立つまでは、あとに書いた範囲かマップ全体の出現表）。
- 町でないマップ（ダンジョンなど）に `respawnMap` を書くと、そこで全滅したときにその町の旅籠の前（町の人に介抱される）へ戻ります。
- ワールドマップのように地域がまたがるマップには `respawnZones`（範囲と町）を書くと、その範囲で全滅したときにその町へ戻ります（`respawnMap` より優先）。範囲に `flag` を書くと、そのフラグが立っているときだけその範囲を使います（伊賀のまわりは、お凛が加わるまでは名古屋へ戻る）。

イベントが参照する道具・敵・仲間・移動先は、`src/data/events.test.ts` が確かめます。

## 手順

| type | 内容 |
| --- | --- |
| `say` | 台詞（1 要素が 1 ページ）。`{hero}` は主人公の名前。`linesF` があれば女主人公のときはそちら。名前の後ろに〈怒〉〈悲〉を書くと、その表情の顔を出す（例: `霞〈怒〉「……」`。印は画面に出ない。表情差分は主人公と仲間だけ。`src/data/faces.ts`） |
| `setFlag` | フラグを立てる（`value: false` で下ろす） |
| `if` | フラグが立っていれば `then`、なければ `else` |
| `choice` | 選択肢。選んだ `steps` を行い、そのあと続きに戻る |
| `giveItem` / `giveMoney` | 道具・装備品、お金を渡す。持ちきれない（99 個を超える）道具は渡さず、`ifFull` があればそれを行う |
| `addJingi` | 仁義ポイントを増やす（負なら減らす。0〜上限 100 に収める。`src/systems/jingi.ts`）。台詞の `{jingi}` はその時点の仁義ポイントに置き換わる |
| `join` | 新しい仲間を加える（パーティーの平均レベル〈切り捨て、最低 1〉、加入時の装備）。ゲスト（`guestLevel` のある人物。第 5 章の榊兵庫）と、加入時のレベルが決まっている人物（`joinLevel`。お凛は Lv1）はそのレベルで加わる。平均レベルには `joinLevel` のある人物を数えない。加入済み・一時離脱中（`away` にいる）・満員なら何もしない。一時離脱からの復帰は `rejoin` を使う |
| `leave` | 仲間を一時的に抜く。経験値と装備は `away` に預ける（第 5 章の霞）。ゲストは預けずに抜ける。主人公と、いない仲間には何もしない |
| `rejoin` | 一時離脱中（`away` にいる）の仲間を戻す（第 6 章の霞）。装備はそのまま、経験値はその時点のパーティーの平均レベル（切り捨て）まで引き上げ（下げない）、HP・MP は満タン。`away` にいない・満員なら何もしない |
| `heal` | 全員を全回復する |
| `battle` | 戦闘。勝つか逃げれば続きへ。`canEscape` を省くと逃げられない。`ifLose` があれば負けても全滅にせず（倒れた仲間は HP 1 で起き上がる）、`ifLose` を行う。なければ通常の全滅でイベントは終わる |
| `warp` | 場所を移す（移った先で続きを行う） |
| `actor` / `walk` / `face` / `vanish` / `wait` | 演出（下の「演出」）。人を出す・歩かせる・向きを変える・消す・待つ |
| `end` | ここで終える |
| `ending` | イベントを終え、エンディング（エンドロールは流さず、黒い画面に「終劇」とだけ出し、決定でタイトルへ戻る。`src/scenes/EndingScene.ts`）を出す。終章のからくり大権現を倒したあとに使う |

## 演出

地の文で人の動きや居場所を語らず、人を画面に出して動かして見せます（テストプレイで「地の文で全部を語っている」「その場にいない人が喋る」と指摘された）。
台詞を言う人は、その場面の画面にいるようにします。`events.ts` の先頭に短い書き方（`actor`・`enemyActor`・`walk`・`face`・`faceTo`・`vanish`・`wait`・`partyOut`・`partyIn`）があります。

| type | 内容 |
| --- | --- |
| `actor` | 人をイベントの間だけ出す。`sprite`（人の画像）か `enemy`（戦闘にしか出ない敵を、戦闘の画像の半分の大きさで）のどちらか。`enemy` は `scale` で大きさを変えられ（1 で戦闘と同じ大きさ。終章のからくり大権現の巨大な姿）、`grow` を付けると半分の大きさからふくらむ（変身）。`x`・`y` を省くと主人公の足元から隣の空いたマスへ 1 歩出る（一行の仲間が主人公から出てくる。`partyOut`） |
| `walk` | 歩かせる。`who` は `'hero'`・マップの NPC の ID・`actor` の ID。`path` は `u`・`d`・`l`・`r` の並び。`to` に人の ID か `{ x, y }` を書くと、そこまで横、縦の順にまっすぐ歩く（仲間が主人公に戻る `partyIn`、戸口に入るとき）。通れないマスの手前で止まる。`wait: false` なら歩き出したらすぐ次へ進む（二人を一緒に歩かせる。歩き終える前にイベントが終わったり戦闘に入ったりしないよう、あとにもっと長い歩きか `wait` を挟む）。人どうしはぶつからないので、主人公のマスを通らない道にする |
| `face` | 向きを変える。`dir` か `toward`（その人のほうを向く） |
| `vanish` | 人を見えなくする（イベントの間。マップの NPC を後まで消すときは `hideFlag` も立てる） |
| `wait` | 待つ（ミリ秒） |

- `actor` で出した人はイベントが終わると消える。動かしたマップの NPC は元の位置に戻る。残す人はマップの NPC（`showFlag`・`hideFlag`）で置く。
- 戦闘をはさんでも、出した人・動かした人はその姿のまま戻る（`EventRunner.stage`）。`warp` で別の場所へ移ると消える。
- 地の文は、調べた物の説明、手に入れた物・仲間に加わったなどの知らせ、画面で見せられない音（「ズシン……」）だけにする。主人公の話す内容は主人公の台詞にする（女主人公の言葉づかいは `linesF`）。
- `src/data/eventStage.test.ts` が、イベントを始めるマップで、出す場所・歩く道が通れるマスか、動かす人がいるかを分岐ごとに確かめる（主人公の位置が分からないイベントでは、主人公の隣に出た人の道は見ない）。
  話しかけたときのイベントでは、主人公は話す相手の隣のどれかに立っているので、ほかの人をそのどのマスにも出したり通らせたりしないことも見る。主人公を歩かせると、その先は見ない（`to` に行き先のマスを書けば、そこを主人公の位置として見続ける。佐和山の盗人）。

## 例

```ts
myEvent: {
  id: 'myEvent',
  steps: [
    { type: 'if', flag: 'done', then: [{ type: 'say', lines: ['もう用はない'] }], else: [
      { type: 'say', lines: ['{hero}、頼みがある'] },
      { type: 'choice', prompt: '引き受けるか？', options: [
        { label: 'はい', steps: [{ type: 'battle', enemies: ['yamainu'], level: 2 }, { type: 'setFlag', flag: 'done' }] },
        { label: 'いいえ', steps: [{ type: 'end' }] },
      ] },
    ] },
  ],
},
```

戦闘や `warp` でフィールドを離れる間、途中のイベントは `state.ts` が預かり、戻ってきたフィールドが続きを行います。途中のイベントはセーブしません（記録は飛脚・親分の屋敷・もぐりの宿でだけ行うため、イベントの途中で記録されることはない）。
