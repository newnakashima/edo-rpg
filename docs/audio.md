# 音楽・効果音の一覧

必要な曲と効果音、どの場面でどの曲を鳴らすかをまとめます。
シーンは、ここに挙げたキー（ID）で `src/systems/audio.ts` の呼び出し口（`playBgm`・`playJingle`・`playSe`）を呼びます。曲は書き出したものから鳴ります。まだない曲は代わりの曲を鳴らします。効果音はまだ鳴らしません（一覧は下の「効果音（SE）」）。

曲は MIDI で作曲し、Ogg Opus に書き出します。作り方は `.claude/skills/music-composition/SKILL.md`、曲の素材（core-theme・motiv）とその使い方の一覧は `music/catalog.md` にあります。

## 曲（BGM）

シナリオ（[story.md](story.md)）・`src/data/maps.ts` の全マップ（町・ダンジョンなど手書きの 43 と、建物・民家から作られる屋内）・イベントの戦闘（`src/data/events.ts`）を突き合わせて洗い出した一覧です（2026-11-15）。
「優先」は作る順の目安です。A は最初にそろえる曲、B は場面の色を足す曲、C はなくても代わりの曲で困らない曲です。まだない曲を鳴らそうとしたときは「代わり」の曲を鳴らします（代わりもなければ、その上の代わりをたどる）。

### コードでの鳴らし方

- `src/systems/audio.ts` の `BGM_IDS` に上の ID をすべて並べ、`BGM_FALLBACK` に代わりの曲の表を置く。`resolveBgm` が、まだ書き出していない曲の代わりをたどる（書き出した曲は `setAvailableBgm` で教える。どれもなければ無音）。
- 書き出した曲は `src/data/bgmTracks.ts` が `music/midi/<id>.json` から拾い、起動時（`src/main.ts`）に `setAvailableBgm` で教える。音は `public/assets/audio/bgm/<id>.ogg`。
- 再生は `src/ui/bgmPlayer.ts`（Web Audio）。ループする曲は前奏の後（`loop_start_seconds`）から曲の終わりまでを繰り返す。ジングルの間は曲を止め、鳴り終えたら止めた位置から戻す。ジングルの途中で別の曲に替われば、ジングルを切る。最初の操作（タップ・キー）で音を出し始め、画面が隠れている間は止める。
- `playBgm(id, fallback)` はループする曲を鳴らす。いま鳴らしている曲と同じなら、頭から鳴らし直さずに続ける。`null` で止める。`playJingle(id)` はループしない曲（勝利・全滅・一泊・加入・終劇）を 1 度鳴らし、終われば前の曲に戻す。
- マップの曲はマップの `bgm` に書く（`src/data/maps.ts`）。建物・民家の屋内は、作るときに町の `bgm` を入れる。親分の屋敷・寺社・賭場は、屋内の施設の人（`action` が `oyabun`・`temple`・`tobaku`）で決め、`bgmFallback` に町の曲を入れる（`src/data/buildings.ts` の `buildingBgm`）。お祓いをしない寺（京の五重塔の寺、金沢の寺町の寺・禅寺・仕掛け寺）は、建物の定義に `bgm` を書く。
- イベントの手順 `bgm` で場面の曲に替える（`src/data/events.ts` の `bgm()`）。`FieldScene` は、イベントの途中ならその曲を、終わったか替えていなければマップの曲を鳴らす（`syncBgm`）。戦闘や `warp` をはさんでも、場面の曲は `EventRunner` が持っているので続く。終章は `ending` の手順で終わるので、浜松の bgm_ending のまま「終劇」へ移る（案にあった `keep` は要らなかった）。
- イベントの `battle` の `bgm` を `BattleScene` に渡し、書いていなければ bgm_battle にする。勝てば曲を止めて bgm_victory、全滅すれば bgm_defeat（`ifLose` のある戦闘では鳴らさない）。
- `join`・`rejoin` で仲間が実際に加わったら bgm_join、親分の屋敷・もぐりの宿で泊まったら bgm_inn を鳴らす。`EndingScene` は曲を止めて bgm_shugeki を鳴らす。

## 効果音（SE）

シーン（`src/scenes/`）・メニュー（`src/ui/`）・戦闘（`src/systems/battle.ts` の `BattleEvent`、`src/data/skills.ts`）・イベント（`src/data/events.ts` の擬音の台詞）を突き合わせて洗い出した一覧です（2026-11-15）。
「優先」は作る順の目安です。A は最初にそろえる音（操作と戦闘の基本）、B は場面の手ごたえを足す音、C は台詞の擬音で足りていて、なくても困らない音です。
「長さ」は目安です。戦闘は 1 つの出来事を 650 ms ごとに進めるので、戦闘の音は 0.6 秒以内に収めます（戦闘の後のページで鳴らす se_levelup は除く）。
効果音は Python（numpy・scipy）で波形を合成し、Ogg Opus（48 kHz）で `public/assets/audio/se/<ID>.ogg` に書き出します（作り方のスキルは別に作る）。

### コードでの鳴らし方（効果音）

- `src/systems/audio.ts` の `SeId` を上の ID に合わせる（いまは 8 個）。書き出した効果音だけを鳴らし、まだないものは無音にする。
- メニューの音は `src/ui/widgets.ts` の `Menu`（移動・決定・取消・選べない）と `MessageWindow.advance` でまとめて鳴らす。
- 戦闘の音は `BattleScene` で 1 つの出来事を進めるところ（`describe(e)` の隣）で、出来事から音を選ぶ。
  - 通常攻撃は、攻撃した仲間の武器で選ぶ（刀・槍は se_slash、玄道の杖は se_hit、お凛の鉄砲は se_gun）。敵の通常攻撃（`attack`）は、味方が受けたときの se_damage だけにする。表の「敵の斬る技」「敵の撃つ技」は、敵の技（`skill`）のこと。
  - 技は、`src/data/skills.ts` の定義に `se` を足して書く。書いていなければ、`physical` は se_slash、属性 `fire` は se_fire、`thunder` は se_thunder、そのほかの `magic` は se_magic、`heal` は se_heal、`status` は効く状態で、強くなる状態（`atkUp`・`defUp`・`evade`・`critUp`）は se_buff、弱くなる状態（`atkDown`・`accDown`）と酒の酔い（`drunk`）は se_debuff、状態異常（`Ailment` の 5 つ）は se_ailment にする。
  - 既定で合わない技には `se` を書く。お凛の鉄砲の技（`magic`）は se_gun、`physical` のうち殴る・投げる・噛む技は se_hit、手裏剣の技は se_shuriken、敵の鉄砲の技（鉄砲・ぶどう弾）は se_gun、大筒・権現砲は se_cannon。
- フィールドの出口（`src/data/maps.ts` の `ExitDef`）に `se` を足し、書いていなければ se_door にする（石段・洞窟は se_stairs）。
- イベントの手順に `{ type: 'se'; id: SeId }` を足す（`src/data/eventTypes.ts`・`src/systems/eventScript.ts`）。`giveItem`・`giveMoney`・`addJingi`・`heal` の手順は、手順そのものが音を鳴らす。
