# テストプレイの指摘の確認（フェーズ 6）

## 確かめ方

- コード: goal の項目ごとに、実装・データ・テストを読み、goal の文と design の決定を満たすかを見た（操作・メニュー、バランス・道具、町・シナリオの 3 つに分けた）

## 直したこと

- 終章のからくり大権現の戦いの前後で、画面にいない玄道が話していた。玄道を出して台詞を言わせ、祝詞を唱える地の文は玄道の台詞にした
- 一行の仲間（霞・玄道・お凛・兵庫）が台詞を言うとき、その仲間が画面に出ていることを、すべてのイベントの分岐ごとに確かめるテストを足した（`eventStage.test.ts` の「台詞を言う仲間が画面にいる」）

## 残したこと（次の作業）

- 賭場・居酒屋・妓楼の頼まれごと（45 件）と親分の頼み（14 件）で、イカサマ師・酔っ払い・酔った侍・押しかけてきた相手が画面に出ないまま話す。負けたときに「出ていった」「引き上げていった」の地の文がある。妓楼は「夜が更けたころ…」の地の文で始まる（`src/data/jingiRequests.ts`・`src/data/oyabunRequests.ts`）。相手を戸口から入ってこさせ、話させ、去らせる演出が要る。屋内の形が町ごとに違うので、戸口から主人公の隣まで回り込んで歩かせる仕組み（通れるマスをたどる道）を足して、別の PR で直す
